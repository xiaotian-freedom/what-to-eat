# 用户登录接口对接说明

## 概述

登录页面已经完成了接口对接，目前支持**密码登录**方式：

- 支持手机号或用户名登录
- 使用密码进行身份验证

## 功能特性

### ✅ 已实现功能

1. **统一登录模式**

   - 支持手机号登录
   - 支持用户名登录
   - 使用密码进行身份验证

2. **表单验证**

   - 用户名/手机号必填验证
   - 密码长度验证（至少 6 位）

3. **用户体验优化**

   - 记住我功能
   - 自动填充上次登录的用户名/手机号
   - 加载状态显示

4. **错误处理**
   - 详细的错误提示信息
   - 网络错误处理
   - 验证失败反馈

## API 接口说明

### 密码登录

**接口**：`POST /api/auth/login`

**请求参数**：

```json
{
  "username": "用户名或手机号",
  "password": "password123"
}
```

或者：

```json
{
  "phone": "13800138000",
  "password": "password123"
}
```

**响应格式**：

```json
{
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "user_id": 1,
  "username": "用户名",
  "avatar_url": null
}
```

## 登录流程

### 密码登录流程

1. 用户输入用户名/手机号和密码
2. 前端验证表单格式
3. 调用登录 API
4. 成功后保存 token 和用户信息
5. 跳转到首页

## 错误处理

### 常见错误类型

1. **用户名/手机号为空**

   - 提示：请输入手机号或用户名
   - 处理：阻止提交，高亮输入框

2. **密码长度不足**

   - 提示：密码长度至少 6 位
   - 处理：阻止提交，高亮输入框

3. **登录失败**

   - 提示：手机号或密码错误，请检查后重试
   - 处理：显示错误信息

4. **网络错误**
   - 提示：登录失败，请稍后重试
   - 处理：显示通用错误信息

## 配置说明

### 1. 后端配置

确保后端服务器支持以下接口：

- `POST /api/auth/login` - 用户登录（支持 username 或 phone 字段）

### 2. 前端配置

Vite 代理配置（已配置）：

```typescript
proxy: {
  '/api': {
    target: 'http://localhost:8000',
    changeOrigin: true,
  },
},
```
