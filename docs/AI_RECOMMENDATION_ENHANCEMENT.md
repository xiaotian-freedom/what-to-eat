# AI 推荐系统增强 - 扩展推荐功能

## 🚀 新增功能

为了解决推荐结果重复率高、缺乏趣味性的问题，我们对 DeepSeek AI 推荐系统进行了重要增强。

## ✨ 主要改进

### 1. 智能扩展推荐

- **问题**：现有菜品列表有限，AI 只能从固定选项中选择，导致推荐重复
- **解决方案**：允许 AI 推荐经典中餐菜品，不局限于现有列表
- **实现方式**：新增 `isExtendedRecommendation` 标志，支持 AI 创建新的菜品推荐

### 2. 优化的提示词策略

```
**重要提示**：如果可选菜品列表中的选项较少或重复性高，你可以：
1. 优先从现有列表中选择最合适的菜品
2. 如果现有菜品都不太合适，可以推荐一道符合当前情况的经典中餐菜品

**推荐策略**：
- 优先考虑用户的心情、天气、时间等因素
- 注重饮食营养搭配和季节性
- 避免过于重复的推荐，增加多样性
- 考虑菜品的制作难度和普及程度
```

### 3. 增强的上下文信息

```
额外说明：
- 如果现有菜品选择较少或重复性高，请考虑推荐一些经典中餐菜品
- 推荐时请考虑营养搭配、制作难度、季节性等因素
- 尽量避免过于重复的推荐，增加用餐的趣味性
```

## 🔧 技术实现

### 1. 扩展 AI 响应格式

```typescript
interface AIRecommendationResponse {
  recommendedFoodId: string; // 菜品ID或新推荐菜品名称
  confidence: number;
  reasons: string[];
  explanation: string;
  score: number;
  isExtendedRecommendation?: boolean; // 新增：是否为扩展推荐
}
```

### 2. 智能菜品对象创建

当 AI 推荐新菜品时，系统会自动创建临时 Food 对象：

```typescript
food = {
  id: `ai_recommendation_${Date.now()}`,
  name: aiResponse.recommendedFoodId, // AI 推荐的菜品名称
  category: '智能推荐',
  categoryColor: '#6366f1',
  tags: ['AI推荐', '中餐'],
  description: aiResponse.explanation,
};
```

### 3. 用户界面标识

在结果页面显示 AI 扩展推荐的特殊标识：

```vue
<!-- AI 扩展推荐标识 -->
<div v-if="isAIExtendedRecommendation" class="flex items-center justify-center mt-1">
  <span class="text-xs bg-gradient-to-r from-purple-500 to-pink-500 text-white px-2 py-1 rounded-full">
    🤖 AI 推荐
  </span>
</div>
```

## 📈 预期效果

### 推荐多样性提升

- **原来**：仅限于用户已添加的菜品（可能只有 5-10 道）
- **现在**：可以推荐任何符合条件的中餐菜品（理论上无限制）

### 用户体验改善

- **更有趣**：不再局限于重复的选择
- **更智能**：AI 可以推荐用户没想到的菜品
- **更实用**：考虑营养搭配、季节性等实际因素

### 推荐质量提升

- **更精准**：基于当前情况推荐最合适的菜品
- **更全面**：考虑制作难度、普及程度等因素
- **更个性化**：结合天气、心情、时间等多个维度

## 🎯 使用场景示例

### 场景 1：菜品列表较少

- **输入**：用户只添加了 3 道菜（米饭、面条、馒头）
- **AI 行为**：检测到选择单调，推荐"宫保鸡丁"
- **结果**：用户获得营养丰富、符合当前心情的新选择

### 场景 2：天气因素考虑

- **输入**：寒冷冬日，用户心情低落
- **AI 行为**：推荐"热腾腾的羊肉汤"作为扩展推荐
- **结果**：温暖身心的完美选择

### 场景 3：营养搭配优化

- **输入**：用户列表都是高热量食物
- **AI 行为**：推荐"清蒸鲈鱼"作为健康选择
- **结果**：平衡营养的明智建议

## 🔍 技术特性

### 智能判断机制

1. **优先级**：现有菜品 > 扩展推荐
2. **触发条件**：菜品列表少、重复性高、不适合当前情况
3. **安全保障**：始终有本地算法作为备选

### 缓存和性能

- **智能缓存**：扩展推荐也会被缓存，避免重复 API 调用
- **快速降级**：AI 失败时立即切换到本地算法
- **用户体验**：无论何种情况都能获得推荐

## 🛡️ 安全考虑

### 数据验证

### 用户反馈

- **解释说明**：AI 会解释为什么推荐这道菜
- **可追溯性**：所有推荐都有详细的推理过程
