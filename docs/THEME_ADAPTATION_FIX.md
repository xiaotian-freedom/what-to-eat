# 成就系统主题适配修复

## 问题描述

成就系统界面在切换主题时存在适配不完整的问题，部分内容在深色主题或其他主题下看不清，影响用户体验。

## 修复的组件

### 1. AchievementBottomSheet.vue

**问题：**

- 成就统计背景透明度过低（0.1），在某些主题下几乎看不见
- 成就图标背景透明度不一致
- 部分颜色硬编码，没有使用主题系统变量
- 成就统计部分使用半透明渐变背景，文字对比度不足
- **成就图标背景透明度过低（0.3/0.2），图标本身没有明确的颜色设置，在某些主题下几乎看不见**

**修复：**

- 将成就统计背景透明度从 0.1 调整为 0.15
- 将成就图标背景透明度统一调整为 0.3（已解锁）和 0.2（未解锁）
- 确保所有颜色都使用 CSS 变量
- **重新设计成就统计部分**：
  - 移除半透明渐变背景，改用实心背景 `var(--color-surface)`
  - 添加边框 `2px solid var(--color-border)` 增强可见性
  - 添加阴影效果提升层次感
  - 添加进度条可视化完成度
  - 确保文字颜色与背景有足够对比度
- **优化成就图标可见性**：
  - 提高背景透明度：已解锁 0.6，未解锁 0.4
  - 添加边框：已解锁使用强调色边框，未解锁使用边框色
  - 明确图标颜色：已解锁使用强调色，未解锁使用次要文字色
  - 添加阴影效果增强立体感
  - 添加主题过渡动画

### 2. AchievementPanel.vue

**问题：**

- 完全使用硬编码的颜色类（如 `bg-white/90`, `text-gray-800`, `bg-green-50` 等）
- 在不同主题下显示效果差异很大
- **成就图标没有明确的颜色设置，在某些主题下不够清晰**

**修复：**

- 将所有硬编码颜色类替换为使用主题系统的 CSS 变量
- 使用 `var(--color-surface)` 作为背景色
- 使用 `var(--color-text)` 和 `var(--color-textSecondary)` 作为文字颜色
- 为成就项添加主题过渡动画
- **为成就图标添加明确的颜色设置**：
  - 已解锁成就图标使用强调色 `var(--color-accent)`
  - 未解锁成就图标使用次要文字色 `var(--color-textSecondary)`

### 3. ChallengeStatus.vue

**问题：**

- 使用硬编码的颜色类（如 `text-red-600`, `text-gray-700`, `bg-gray-200` 等）
- 进度条使用固定的蓝色渐变

**修复：**

- 将所有硬编码颜色替换为 CSS 变量
- 进度条使用主题系统的渐变色
- 为提示信息使用主题相关的颜色

### 4. ResultCard.vue

**问题：**

- 描述文字使用 `text-gray-600`
- 标签和特色标识使用硬编码的颜色

**修复：**

- 描述文字使用 `var(--color-textSecondary)`
- 标签使用主题系统的渐变色
- 特色标识使用主题相关的颜色

### 5. ActionButtons.vue

**问题：**

- 按钮文字颜色使用 `text-gray-700`

**修复：**

- 按钮文字颜色使用 `var(--color-text)`
- 添加主题过渡动画
- 统一阴影效果

### 6. LanguageSwitcher.vue

**问题：**

- 使用硬编码的颜色类

**修复：**

- 完全重构为使用主题系统的 CSS 变量
- 添加主题过渡动画

## 使用的 CSS 变量

```css
--color-primary: 主色调
--color-secondary: 次要色调
--color-accent: 强调色
--color-background: 背景色
--color-surface: 表面色
--color-text: 主要文字颜色
--color-textSecondary: 次要文字颜色
--color-border: 边框颜色
--color-shadow: 阴影颜色
```

## 主题过渡效果

为所有修复的组件添加了 `theme-transition` 类，确保主题切换时有平滑的过渡动画：

```css
.theme-transition {
  transition: background-color 0.3s ease, color 0.3s ease, border-color 0.3s ease, box-shadow 0.3s
      ease;
}
```

## 成就统计优化详情

### 问题分析

原来的成就统计部分使用了半透明的渐变背景（opacity: 0.2），在某些主题下文字几乎看不见，特别是在深色主题下。

### 解决方案

1. **背景优化**：改用实心背景色 `var(--color-surface)`，确保在所有主题下都有足够的对比度
2. **边框增强**：添加 `2px solid var(--color-border)` 边框，增强视觉层次
3. **阴影效果**：添加阴影提升立体感
4. **进度可视化**：添加进度条直观显示完成度
5. **文字对比**：确保数字和标签文字与背景有足够对比度

### 效果对比

- **修复前**：半透明渐变背景，文字对比度低，在某些主题下几乎看不见
- **修复后**：实心背景 + 边框 + 阴影，文字清晰可见，进度条可视化

## 成就图标优化详情

### 问题分析

原来的成就图标存在以下问题：

- 背景透明度过低（0.3/0.2），在某些主题下几乎看不见
- 图标本身没有明确的颜色设置，依赖默认文字颜色
- 缺乏视觉层次，难以区分已解锁和未解锁状态

### 解决方案

1. **背景透明度提升**：

   - 已解锁成就：0.3 → 0.6
   - 未解锁成就：0.2 → 0.4

2. **边框增强**：

   - 已解锁成就：`2px solid var(--color-accent)`
   - 未解锁成就：`2px solid var(--color-border)`

3. **图标颜色明确化**：

   - 已解锁成就：`var(--color-accent)`（强调色）
   - 未解锁成就：`var(--color-textSecondary)`（次要文字色）

4. **阴影效果**：

   - 已解锁成就：`0 2px 8px rgba(0, 0, 0, 0.15)`
   - 未解锁成就：`0 1px 4px rgba(0, 0, 0, 0.1)`

5. **主题过渡**：添加 `theme-transition` 类确保平滑切换

### 效果对比

- **修复前**：低透明度背景，无明确颜色，在某些主题下几乎看不见
- **修复后**：高透明度背景 + 边框 + 明确颜色 + 阴影，清晰可见且层次分明

### 设计原则

- **高对比度**：确保图标在所有主题下都清晰可见
- **状态区分**：通过颜色和边框明确区分已解锁和未解锁状态
- **视觉层次**：通过阴影和边框增强立体感
- **主题一致**：使用 CSS 变量确保主题切换的一致性
